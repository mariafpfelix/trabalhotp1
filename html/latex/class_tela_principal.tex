\doxysubsection{Descrição detalhada}
Responsavel pela interacao com o usuario no console. 

Exibe os menus do sistema Kanban, le as opcoes digitadas e mostra as listagens de pessoas e projetos. O menu principal se adapta ao papel do usuario autenticado.
