\doxysubsection{Descrição detalhada}
Dominio que representa a senha de acesso de uma pessoa. 

Regras de formato:
\begin{DoxyItemize}
\item Exatamente 5 caracteres.
\item Apenas letras (A-\/Z, a-\/z) e digitos (0-\/9).
\item Deve conter pelo menos uma letra e pelo menos um digito. 
\end{DoxyItemize}
