Hierarquia de Classes
Esta lista de hierarquias está parcialmente ordenada (ordem alfabética):
 CCartaoAtividadeRepresenta uma atividade de um quadro Kanban
 CCartoesAtividadesGerencia os cartoes de atividades no banco SQLite
 CControladoraCartoesAtividadesControla as operacoes relacionadas aos cartoes de atividade
 CControladoraPessoasControla as operações relacionadas às pessoas
 CControladoraProjetosControla as operações relacionadas aos projetos
 CControladoraQuadrosControla as operações relacionadas aos quadros
 CEmailDominio que representa um endereco de email
 CEstadoDominio que representa o estado de um cartao de atividade
 CICartoesAtividadesInterface para operacoes relacionadas a cartoes de atividade
  CServicoCartoesAtividadesImplementa as regras de negocio dos cartoes de atividade
 CIdentificadorDominio que representa o identificador de projetos, quadros e cartoes
 CIPessoasInterface para operacoes relacionadas a pessoas
  CServicoPessoasImplementa os servicos relacionados a pessoas
 CIProjetosInterface para operacoes relacionadas a projetos
  CServicoProjetosImplementa os servicos relacionados aos projetos
 CIQuadrosInterface para operacoes relacionadas a quadros
  CServicoQuadrosImplementa os servicos relacionados aos quadros
 CLimiteDominio que representa o limite WIP (Work In Progress) de um quadro
 CNomeDominio que representa o nome de pessoas, projetos, quadros e cartoes
 CPapelDominio que representa o papel de uma pessoa no sistema
 CPessoaRepresenta uma pessoa cadastrada no sistema Kanban
 CPessoasGerencia o armazenamento de pessoas no banco de dados
 CPrioridadeDominio que representa a prioridade de um cartao de atividade
 CProjetoRepresenta um projeto cadastrado no sistema Kanban
 CProjetosGerencia o armazenamento de projetos no banco SQLite
 CQuadroRepresenta um quadro Kanban pertencente a um projeto
 CQuadrosGerencia o armazenamento de quadros Kanban
 CSenhaDominio que representa a senha de acesso de uma pessoa
 CTamanhoDominio que representa o tamanho (esforco) de um cartao de atividade
 CTelaPrincipalResponsavel pela interacao com o usuario no console
 CTextoDominio que representa textos descritivos, como a descricao de projetos e cartoes
 CTimestampDominio que representa uma data e hora
